# Security Policy

## Supported Versions

Security updates are currently focused on the latest release of Jarvis.

| Version | Supported |
| ------- | --------- |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in Jarvis, please report it through [GitHub Issues](../../issues) or GitHub's private vulnerability reporting feature, if enabled for this repository.

Please include a clear description of the vulnerability, steps to reproduce it, its potential impact, and any relevant logs or screenshots. **Do not publicly disclose sensitive details before the issue has been investigated.**

Please avoid sharing API keys, passwords, private conversation data, or other sensitive information in public reports.

Thank you for helping make Jarvis safer and more reliable.
